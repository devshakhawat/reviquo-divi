Setup instructions

1. Install and activate. Upload the plugin zip under Plugins → Add New → Upload Plugin, then activate. WooCommerce must be active, and product reviews must be enabled under WooCommerce → Settings → Products → Reviews.

2. Turn on the review options. Go to ReviQuo → Review Settings → General. Choose which options appear in the product review form: webcam recording, video file upload, and photo upload. Set the maximum recording length, mark any of them as required, and decide whether reviews with media are published immediately or held for moderation.

3. Style the storefront. In the Appearance tab, adjust the colors, text, icons, and fonts of the record, upload, and photo buttons and the recording modal so they match your theme. Optional extras such as the rating summary, review filters, verified-owner badge, and rich snippets for search engines are switched on in the same screen.

4. Set up review reminders. Open ReviQuo → Email Reminders, enable reminders, and set the sender name and address. Add one or more rules: choose the order status that triggers the email (Completed by default), the number of days to wait, and the subject and message. Scheduleed on the same page.

5. Moderate reviews. New reviews with video or photos appear under ReviQuo → Reviews. Preview media in the lightbox, then approve, unapprove, mark as spam, or trash reviews individually or in bulk.

6. Display reviews anywhere (optional). Reviews with media show automatically on the product page. To place review displays elsewhere, go to ReviQuo → Review Shortcode, create a display, and add it to any page using the [reviquo id="…"] shortcode, the Product Reviews block widget, or the Divi module.
